Vérifier un document

Certificat d’agrément ou titre réglementaire — Autorité Congolaise de Réglementation Pharmaceutique

Le QR code est illisible ? Saisissez le numéro et le code de contrôle imprimés en haut à droite du document.

Le résultat affiche l’état réel du document lu sur le registre national : valide, expiré ou suspendu. Un document dont le numéro ou le code ne correspond à aucun enregistrement doit être considéré comme non authentique.
